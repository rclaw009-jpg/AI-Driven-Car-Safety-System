## 📌 Overview

Road accidents are one of the leading causes of death worldwide. This project proposes an **AI-driven accident detection system** that uses **Convolutional Neural Networks (CNNs)** to classify crash and non-crash events from dashcam footage in **real-time**.

The system also integrates:
- 📍 **GPS-based emergency alerts** — automatically notifies emergency services with exact location when a crash is detected
- 🌦️ **Weather-based driver warnings** — fetches live weather data and alerts drivers of hazardous conditions (rain, fog, snow)

---

## ✨ Key Features

- ✅ Real-time crash detection from dashcam footage
- ✅ **90.4% test accuracy** on 75,000 image dataset
- ✅ GPS alert via Twilio SMS to emergency contacts
- ✅ Live weather API integration for proactive driver safety
- ✅ Trained on the Car Crash Dataset (CCD) from Kaggle
